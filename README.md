# JEE 2027 Study Companion

A pink-and-white, responsive single-page study planner.

## Run it
1. Extract the ZIP.
2. Open `index.html` in a modern browser, or deploy the folder to a static host such as GitHub Pages or Netlify.
3. On first open, the compliment popup appears. You can change its behavior in Settings.

## Included
- Dashboard with focus totals, task progress, syllabus completion, and subject progress
- Pomodoro timer with 25/5, 50/10, and custom intervals
- Editable starter topic tracker for Physics, Chemistry, and Mathematics
- To-do list with subject and priority
- Monthly calendar highlighting dates tasks were created
- Revision queue
- Mock-test tracker and score chart
- PYQ/practice log
- Notes
- Daily habits
- Pink compliment popup with 50+ messages
- Local browser storage and JSON export/import

## Important limitations
- This starter syllabus is a useful editable topic list, not a verified complete JEE Main/Advanced 2027 syllabus. Check the official 2027 syllabi before relying on it for coverage.
- Data is stored in the current browser on the current device. It does not provide login or cross-device sync. For that, connect a backend such as Supabase and implement authentication and row-level security.
- The calendar is a lightweight monthly view; tasks do not yet have independently editable due dates.
